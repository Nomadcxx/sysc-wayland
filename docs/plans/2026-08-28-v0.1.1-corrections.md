**Step 1: Write the failing core-equivalence test**

Add this test and helper to `cmd/sysc-wayland-scanner/main_test.go`:

```go
func TestScannerReproducesVendoredCoreBinding(t *testing.T) {
	repoRoot, err := filepath.Abs(filepath.Join("..", ".."))
	if err != nil {
		t.Fatal(err)
	}
	input := filepath.Join(repoRoot, "protocols", "wayland.xml")
	output := filepath.Join(t.TempDir(), "client.go")
	runScanner(t, "-pkg", "client", "-prefix", "wl", "-i", input, "-o", output)

	got := normalizeXMLSource(readFile(t, output))
	want := normalizeXMLSource(readFile(t, filepath.Join(repoRoot, "client", "client.go")))
	if !bytes.Equal(got, want) {
		t.Fatal("vendored core XML does not reproduce client/client.go")
	}
}

func normalizeXMLSource(data []byte) []byte {
	lines := bytes.Split(data, []byte("\n"))
	for i, line := range lines {
		if bytes.HasPrefix(line, []byte("// XML file : ")) {
			lines[i] = []byte("// XML file : <source>")
			break
		}
	}
	return bytes.Join(lines, []byte("\n"))
}
```

## Task 2: Correct array request framing

**Files:**

- Modify: `cmd/sysc-wayland-scanner/main_test.go`
- Modify: `cmd/sysc-wayland-scanner/main.go`

**Step 1: Write the failing scanner test**

Add an `arrayRequestProtocol` fixture containing one `array_widget.set_values` request with an array
argument. Generate it in a test and assert that output contains:

```go
valuesLen := client.PaddedLen(len(values))
_reqBufLen := 8 + (4 + valuesLen)
client.PutArray(_reqBuf[l:l+(4+valuesLen)], values)
l += (4 + valuesLen)
```

Name the test `TestScannerFramesArrayRequests`.

**Step 2: Run the test and verify RED**

```bash
go test ./cmd/sysc-wayland-scanner -run TestScannerFramesArrayRequests -count=1 -v
```

Expected: FAIL because generated code allocates only `8 + len(values)` and advances by the raw length.

**Step 3: Implement the minimum generator fix**

For array request arguments, generate a padded length with package-local `PaddedLen` for core bindings
or `client.PaddedLen` for extension bindings. Add `(4 + <name>Len)` to the frame size and cursor. Keep
`PutArray` unchanged so it writes the raw payload length and bytes into the zero-filled padded buffer.

**Step 4: Verify GREEN**

```bash
go test ./cmd/sysc-wayland-scanner -run TestScannerFramesArrayRequests -count=1 -v
go test ./cmd/sysc-wayland-scanner -count=1
```

Expected: both commands pass.

**Step 5: Commit**

```bash
git add cmd/sysc-wayland-scanner/main.go cmd/sysc-wayland-scanner/main_test.go
git commit -m "fix: frame generated array requests"
```
